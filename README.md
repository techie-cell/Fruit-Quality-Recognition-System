## Fruit Fresh Check – AI-Based Fruit Quality Assessment System

Deep learning based Fruit Quality Recognition system using VGG16 and Flask. Identifies fruit type and classifies quality (fresh/rotten) from images. Includes web app, prediction module, and sample test images.
This system can be used in agriculture, food industries, and retail environments to automate fruit inspection and improve quality control.

## 🚀 Features

- Detects multiple fruit types from images
- Classifies fruit quality as **Fresh** or **Rotten**
- User-friendly web interface using Flask
- Upload and test custom fruit images
- Fast and accurate predictions using deep learning
- Organized and easy-to-understand project structure

---

## 🛠️ Technologies Used

- Python
- TensorFlow / Keras (VGG16 Model)
- Flask (Web Framework)
- OpenCV (Image Processing)
- NumPy, Pandas
- HTML, CSS, JavaScript

## 🧠 How It Works

1. User uploads a fruit image through the web interface  
2. Image is preprocessed (resized and normalized)  
3. The trained VGG16 model analyzes the image  
4. The system predicts:
   - Fruit type  
   - Quality (Fresh / Rotten)  
5. Results are displayed instantly on the screen
